# Dee-manta-trend

Dee-Manta-Trend is a music executive and artist management brand behind Manta Music, a modern music artist network built with React + Vite.

Manta Music is a platform designed to connect talented artists, music creatives, executives, and industry professionals while showcasing emerging talent, music projects, artist profiles, and opportunities.

Dee-Manta-Trend represents vision, talent, artist development, management, and the future of music networking.

## Project status
- Landing page is ready
- Signup UI is ready
- Real backend authentication is not connected yet

## Local setup

1. Open a terminal in the project folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in the terminal (usually http://localhost:5173)

## Useful commands

```bash
npm run dev
npm run build
npm run preview -- --host 0.0.0.0
```

## Vercel deployment

1. Push this repo to GitHub.
2. Go to Vercel: https://vercel.com
3. Click Add New Project.
4. Import this repository.
5. Keep the default settings.
6. Click Deploy.

Vercel will detect the Vite app automatically and deploy it.
